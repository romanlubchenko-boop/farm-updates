# Бот розпізнавання рахунків

Продавці надсилають фото рахунку в Telegram. Бот розпізнає суму, звіряє з місячним планом
і показує, скільки залишилось. Адмін керує продавцями і планами, власник веде білінг.

## Ролі

| Роль | Хто | Команди |
|---|---|---|
| Продавець | працівники замовника | фото рахунку, `/stat` |
| Адмін | замовник (`ADMIN_ID`) | `/list` `/add` `/rename` `/remove` `/plan` `/report` `/export` `/billing` |
| Власник | розробник (`OWNER_ID`) | усе з адміна + `/billing` з деталями, `/invoice`, `/paid`, `/rate`, `/backup` |

## Встановлення на сервер

```bash
sudo useradd -r -m -d /opt/receipt-bot bot
sudo -u bot git clone <repo> /opt/receipt-bot/src   # або скопіюйте папку telegram-receipt-bot
cd /opt/receipt-bot && sudo -u bot cp -r src/telegram-receipt-bot/* .
sudo -u bot python3 -m venv venv
sudo -u bot venv/bin/pip install -r requirements.txt
sudo -u bot cp .env.example .env && sudo -u bot nano .env   # токени і ID
sudo cp receipt-bot.service /etc/systemd/system/
sudo systemctl enable --now receipt-bot
sudo journalctl -u receipt-bot -f                           # логи
```

Потрібно: Python 3.10+, доступ до api.telegram.org і api.anthropic.com. Вхідні порти не потрібні.

## Налаштування

Усе в `.env`, див. `.env.example`. Ключове:

- `OWNER_ID`, `ADMIN_ID` — Telegram ID. Дізнатись: написати боту `/start`, він покаже ID.
- `ANTHROPIC_MODEL` — модель розпізнавання. При зміні моделі оновіть ціни `PRICE_*`.
- `MARGIN_PERCENT`, `SUBSCRIPTION_UAH`, `USD_RATE` — білінг.

## Як працює

1. Продавець пише боту `/start`. Адміну приходить запит із кнопкою «Додати як продавця».
2. Адмін задає план: `/plan Іван 150000`. Якщо на новий місяць план не задано, береться попередній.
3. Продавець надсилає фото. Бот показує розпізнану суму з кнопками «Підтвердити / Змінити суму / Скасувати».
4. Після підтвердження продавець бачить план, виконання, залишок і скільки треба в день.
5. Дублі (той самий номер і сума) відхиляються.

## Білінг

Кожен запит до Anthropic записується з вартістю за токенами. Вартість для замовника:
`API × (1 + маржа) × курс + абонплата`. Замовник бачить тариф за рахунок і суму, власник ще й токени та маржу.

- Щодня 09:00 власнику приходить резервна копія бази.
- 1-го числа власнику приходить підсумок минулого місяця з кнопкою «Виставити рахунок замовнику».
- `/paid 2026-09` відмічає оплату, замовник отримує підтвердження.

## Дані

SQLite-файл `bot.db` поруч із ботом. Фото не зберігаються, лише цифри: хто, коли, номер, сума.
